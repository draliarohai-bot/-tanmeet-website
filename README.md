# Tanmeet Website | موقع تنميط

موقع عربي RTL متجاوب لخدمات تنميط العمليات والأتمتة والأنظمة المؤسسية.

## النشر
تم تجهيز GitHub Actions للنشر التلقائي على GitHub Pages من الفرع `main`.

الموقع المتوقع:
https://draliarohai-bot.github.io/-tanmeet-website/

## الملفات
- `index.html` الموقع
- `robots.txt` إعداد محركات البحث
- `sitemap.xml` خريطة الموقع
- `.nojekyll` تشغيل الموقع كملفات ثابتة
- `.github/workflows/pages.yml` النشر التلقائي

## قبل الإطلاق التجاري
أضف بيانات التواصل الرسمية (البريد وواتساب)، والدومين والشعار/صورة المشاركة الاجتماعية عند توفرها. راجع أي أرقام أو شهادات تسويقية قبل نشرها كحقائق.
